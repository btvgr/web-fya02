# Fe y Alegría N.º 2 — Sitio web

## Reglas de desarrollo

- El proyecto se realiza con HTML, CSS y JavaScript.
- No usar frameworks por ahora.
- Mantener HTML, CSS y JavaScript separados.
- Leer `docs/contenido.md` y `docs/diseno.md` antes de realizar cambios importantes.
- No inventar información institucional.
- No eliminar contenido existente sin necesidad.
- No modificar secciones que no estén relacionadas con la tarea solicitada.
- Reutilizar estilos y componentes.
- Usar variables CSS para los colores.
- Mantener el diseño responsive.
- Priorizar la accesibilidad y la legibilidad.
- Mantener ordenados los nombres de archivos y carpetas.
- Antes de hacer cambios grandes, revisar los archivos existentes.
