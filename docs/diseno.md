# Guía visual — Web Fe y Alegría N.º 2

Esta guía define la dirección visual del proyecto antes de desarrollar la interfaz. La identidad corresponde a Fe y Alegría N.º 2.

## Estilo general

La web debe transmitir una imagen:

- Institucional.
- Moderna.
- Juvenil.
- Cercana.
- Limpia.
- Profesional.

Evitar una apariencia infantil. El diseño debe priorizar claridad, confianza y fácil lectura.

## Paleta de colores

| Uso | Color | Código |
| --- | --- | --- |
| Rojo institucional | Rojo principal de identidad y acentos | `#E50922` |
| Rojo oscuro | Estados destacados, contraste y detalles | `#B8071C` |
| Rojo suave | Fondos sutiles, avisos o bloques destacados | `#FDECEF` |
| Blanco | Superficies principales | `#FFFFFF` |
| Fondo | Fondo general de la web | `#FAF8F8` |
| Texto principal | Títulos y contenido principal | `#1C1C1C` |
| Texto secundario | Textos de apoyo y metadatos | `#666666` |

El rojo institucional debe usarse principalmente como acento: botones, enlaces destacados, indicadores y pequeños elementos de identidad. No se debe saturar la página con grandes superficies rojas.

### Colores para ESPECIAL 60 AÑOS

La sección de aniversario puede incorporar, de forma complementaria, los siguientes tonos:

| Uso | Color | Código |
| --- | --- | --- |
| Dorado | Detalles conmemorativos y acentos | `#C9A227` |
| Dorado claro | Fondos suaves o detalles secundarios | `#F3E7B3` |

El dorado se utilizará solo en la sección ESPECIAL 60 AÑOS para conservar su carácter conmemorativo.

## Tipografías

| Elemento | Tipografía |
| --- | --- |
| Títulos | Poppins |
| Texto corrido | Inter |

Los títulos deben tener jerarquía clara y un peso visual suficiente. El texto corrido debe favorecer una lectura cómoda y accesible.

## Estilo de interfaz

- Usar fotografías grandes y de buena calidad como protagonistas del contenido.
- Mantener espacios amplios entre secciones y elementos.
- Presentar noticias, logros y contenidos en tarjetas modernas.
- Aplicar bordes redondeados moderados.
- Usar sombras muy suaves y discretas para separar superficies cuando sea necesario.
- Mantener fondos claros para que el contenido y las fotografías destaquen.
- Incorporar animaciones discretas, breves y funcionales; no deben distraer ni dificultar la navegación.
- Mantener una composición ordenada, con buena jerarquía visual y contraste legible.

## Diseño responsive

La página debe funcionar correctamente en:

- Computadora.
- Tablet.
- Celular.

En pantallas amplias, el contenido puede organizarse en varias columnas cuando la lectura lo permita. En tablet, las secciones y tarjetas deben adaptarse para conservar espacios y legibilidad. En celular, el contenido debe mostrarse principalmente en una columna, con controles cómodos para tocar y textos fáciles de leer.

La navegación principal en celular debe convertirse en un menú hamburguesa.

## Criterios de consistencia

- Aplicar la misma paleta, tipografías, espaciados y estilo de botones en todas las secciones.
- Reservar los colores de aniversario para ESPECIAL 60 AÑOS.
- Dar prioridad a la legibilidad sobre los efectos decorativos.
- Verificar que la interfaz se mantenga clara tanto con fotografías como con contenido textual.
